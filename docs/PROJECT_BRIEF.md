# I Made Zombies — ฉันนี่แหละ คนสร้างซอมบี้

สรุปจาก 5 บทสนทนาที่แสดงใน ChatGPT Project วันที่ 7 ตุลาคม 2026
ตรวจหน้าโปรเจกต์และเลื่อนแต่ละแชตถึงบนสุดแล้ว พบ 5 แชต Sources ว่าง และ Instructions ว่าง
หลังเปลี่ยนเป็นบัญชี Joe k เปิดแชตต้นฉบับทั้ง 5 แชตและโหลดข้อความเก่าย้อนถึงต้นเรื่องได้แล้ว
แชตหลักเริ่มเวลา 09:40 ด้วยแนวคิดสร้างภัยพิบัติซอมบี้ ก่อนปรับเป็นนักวิจัยทดลองกับตัวเอง
สรุปนี้อ้างอิงข้อความของเส้นบทสนทนาปัจจุบัน ภาพที่สร้างและข้อความฉบับแก้ไขใน branch อื่นยังไม่ได้ตรวจทุกเวอร์ชัน

## แกนเกมและวงจรที่ตกลงแล้ว

ชื่ออังกฤษที่ผู้ใช้เลือกคือ I Made Zombies เล่นแนวนอน ใช้ Blender + Godot
ผู้เล่นเป็นนักวิจัยทดลองยากับตัวเองเพื่อสร้างซอมบี้ที่สมบูรณ์แบบและแพร่เชื้อได้ดีที่สุด

ผสมยาใน Lab → กดเริ่มเท่ากับฉีดยา → เข้าเมืองในร่างมนุษย์ → เดินหาจุดเริ่มระบาดขณะมีอาการ → กลายร่างโดยไม่มี countdown → ล่าและแพร่เชื้อ → สรุปผล → กลับไปปรับสูตร

คำขอให้ฉีดหลังเดินเลือกตำแหน่งถูกแก้ภายหลังเป็นฉีดตอนกดเริ่มจาก Lab จึงต้องใช้กฎล่าสุด
ระยะฟักตัวและผลยาไม่บอกก่อนทดลอง ผู้เล่นเรียนรู้ผ่านอาการและผลการเล่น

## ระบบ Serum

- ผู้เล่นผสมสารตั้งต้นและปริมาณเอง ชื่อและจำนวนสารยังไม่กำหนด
- สูตรมีทั้งข้อดีและผลข้างเคียง: ทิศทางควบคุมผิดเพี้ยน ระยะล่าแคบ การมองเห็นลดลงหรือเห็นลาง ๆ เป็นข้อเสนอจากผู้ใช้
- ผู้ใช้ตอบรับระบบทดลองที่มีปฏิกิริยาระหว่างสาร ผลต่อหลายระบบ และสมุด Lab บันทึกสิ่งที่ค้นพบ
- ความรู้จากการทดลองเป็นความก้าวหน้า ไม่ใช่แค่เพิ่ม stat ตาม skill tree
- ผลยาต้องมีความสัมพันธ์กับสูตรให้เรียนรู้และปรับได้; ค่าตัวเลข ตัวอย่างสาร และสูตรที่ปรากฏในแชตเป็นตัวอย่าง ยังไม่ใช่ค่าที่ล็อกสำหรับเกม

## การล่าและเงื่อนไขจบรอบ

- ผู้เล่นควบคุมการเดิน เมื่อเข้าใกล้เหยื่อซอมบี้ไล่จับและกัดอัตโนมัติ
- วิ่งไล่ได้เท่าที่มี stamina หมดแล้วหยุด เหยื่อรอด; ช่วงเดินใช้ฟื้นกำลังตามแนวทางที่ผู้ช่วยเสนอ
- ซอมบี้ที่เกิดใหม่เป็น AI แพร่เชื้อต่อเอง
- ผู้ใช้กำหนดชนะเมื่อคนในด่านติดเชื้อทั้งหมด
- กฎแพ้เดิม: ตัวผู้เล่นถูกกำจัด หรือมนุษย์มีวัคซีนและรักษาคนได้หมด
- ต่อมาผู้ใช้เพิ่มแนวคิดสลับ host ที่กัดเอง ผู้ช่วยจึงเสนอให้ตายแล้วย้ายร่างและแพ้เมื่อไม่มี host เหลือ; ยังไม่มีคำยืนยันกฎตายฉบับใหม่
- วัคซีนสำเร็จแล้วเริ่มรักษาคน แทนแพ้ทันที เป็นรายละเอียดที่ผู้ช่วยเสนอและสอดคล้องกับกฎผู้ใช้ให้รักษาหมดก่อนแพ้

## การตรวจจับและด่าน

- มนุษย์มีระยะสายตาต่างกัน มีกลิ่นซอมบี้ที่ทำให้สงสัยหรือหนีแม้ถูกบังสายตา เป็นข้อเสนอจากผู้ใช้
- ด่านอาจเป็นที่โล่ง ทำให้ถูกเห็นง่าย; ความยากต้องสัมพันธ์กับสภาพแวดล้อมและสูตรยา
- การได้ยิน ฝน ประเภทอาชีพ NPC โรงพยาบาล ฐานทหาร และลำดับความสงสัยเป็นรายละเอียดที่ผู้ช่วยเสนอ
- ไม่มีนาฬิกาบอกเวลาเช้า ใช้แสงและเสียงไก่ขันเตือนให้หาที่หลบแดด

## หน้าจอและเมนูที่คุยไว้

- Loading: cartoon casual รูปทรงเรียบ โทนเข้ม แต่เป็นกลางวัน ตัวละครกำลังเขียวและแหงนมองฟ้าอยู่กลางถนน มีมือซอมบี้เบลอด้วย DOF ใน foreground
- ขอแยกพื้นหลัง มือซอมบี้ โลโก้ และแถบโหลด เพื่อทำ animation
- Main Menu: ผู้ใช้เลือกภาพ 2 ซึ่งผู้ช่วยเรียกว่า Containment Room มีตู้กระจกซอมบี้ นักวิจัย และเมนู STAGES / LAB / COLLECTION / RECORDS / PLAY
- Stages: ขอเป็นแผนที่ เริ่มออกแบบด่านเดียวก่อน
- Lab: ต้องมีหลอดสารเคมี ชุดตวง ชุดแกว่งสาร สารเคมี และเข็มฉีดยา
- Collection: มีการออกแบบภาพแล้ว แต่ข้อความยังไม่ได้ล็อกโครงข้อมูลละเอียด
- Record: ผู้ใช้ยืนยันให้เป็น Experiment History แฟ้มการทดลองแต่ละรอบ ดูสูตร ด่าน ผลการระบาด และใช้สูตรเดิมซ้ำได้
- Gameplay: กฎล่าสุดตัด minimap ปุ่ม skill และตัวเลขผู้รอดชีวิตออก ใช้เสียง/ป้ายประกาศในโลก

## ข้อกำหนดจากผู้ใช้ที่อ่านได้

- เกมมุม isometric จากด้านบน พัฒนาใน workspace Godot นี้
- ช่วงเล่นควบคุมทิศทางเดินไปหาเหยื่อ ไม่มี minimap ปุ่ม skill หรือจำนวนผู้รอดชีวิตบน HUD
- จำนวนผู้รอดชีวิตสื่อผ่านประกาศในโลก ผู้เล่นต้องรอฟังเอง
- กลางวันซอมบี้เคลื่อนที่ช้าลง สูตรยาหรือการกลายพันธุ์อาจทำให้ทนแดดได้
- ต้องการสลับไปควบคุมเฉพาะซอมบี้ที่ผู้เล่นกัดเอง
- ระบบตัวละคร modular: หลายรูปร่าง หัว ผม เสื้อผ้า และอุปกรณ์ ใช้ skeleton และ animation ร่วมกัน
- เมื่อมนุษย์ติดเชื้อควรยังจำได้ว่าเป็นคนเดิม เก็บรูปร่างและเสื้อผ้าไว้ เปลี่ยนท่าทางและผิวตามสถานะ
- ทิศทางภาพล่าสุด: Stylized Hand-Painted Low Poly มีรูปทรงและ silhouette เด่น รายละเอียดใบหน้าและเสื้อผ้าเพ้นท์ลง diffuse texture ไม่ใช่แค่ material สีเรียบ
- ภาพรวม gameplay เป็น 3D low-poly cartoon casual; ผู้ใช้เปลี่ยนข้อเสนอกล้อง third-person เป็น isometric และขอให้ภาพใกล้แนว zomdroid
- ตัวเอกเป็นนักวิจัยอายุประมาณ 25–27 ปี กบฏต่อกฎ ใช้สัดส่วนประมาณ 5 หัว ต้องออกแบบให้เห็นทั้งมนุษย์ เริ่มติดเชื้อ และซอมบี้
- ผู้ใช้ขอ reference ตัวเอกแบบ T-pose สำหรับนำไปปั้น และภายหลังส่งภาพสไตล์ใหม่แทนแนว Albion

## แนวคิดที่ผู้ช่วยในแชตเสนอ ยังต้องแยกจากข้อยืนยัน

- แสงแดดลด stamina และทำความเสียหาย ส่วนเงาช่วยป้องกัน
- ผู้รอดชีวิตหนี แจ้งเตือนตำรวจ อพยพ และมีการรักษา
- ร่างเดิมของ host กำหนดความเร็วและความแข็งแรง ส่วน serum กำหนดคุณสมบัติเชื้อ
- คนที่ถูกกัดขณะผู้เล่นควบคุม host นับเป็น host ใหม่ได้ แต่การกัดโดย AI ไม่นับ
- ร่างที่ควบคุมตายแล้วย้ายไป host ที่เหลือได้; แพ้เมื่อไม่มี host เหลือ
- เสื้อกาวน์ดัดแปลง ผม asymmetrical บูต goggles และของติดตัวเป็นแนวทางที่ผู้ช่วยเสนอ; ยังไม่มีภาพสุดท้ายที่ยืนยันได้จากการตรวจครั้งนี้

## ภาพรวมที่เชื่อมกัน

การทดลองเซรุ่มกำหนดคุณสมบัติเชื้อ ส่วนร่างมนุษย์เดิมกำหนดความแตกต่างของ host
เมื่อเข้าสู่ช่วงแพร่เชื้อ ผู้เล่นอ่านสถานการณ์จากโลกจริง เช่น พฤติกรรม NPC เสียงเตือน แสง และท่าทางตัวละคร
การกัดเองสร้างเครือข่าย host ที่ควบคุมได้ ส่วนฝูง AI ช่วยขยายการระบาด การเปลี่ยนสถานะใช้ตัวละครเดิมเพื่อให้จำเหยื่อได้
ระบบ modular และ animation ร่วมกันจึงรองรับทั้งความหลากหลายของประชากรและการเปลี่ยนมนุษย์เป็นซอมบี้
สไตล์ล่าสุดต้องมี texture เพ้นท์ที่ทำให้ใบหน้าและเสื้อผ้ามีบุคลิก; material สีพื้นอย่างเดียวไม่ตรงทิศทางล่าสุด

## เรื่องที่ต้องกำหนดต่อจากบทสนทนา

- ชื่อสาร จำนวนสาร และสมการผสมจริง
- กฎแพ้เมื่อตัวที่ควบคุมตายหลังเพิ่มระบบสลับ host
- ขนาดด่าน จำนวนประชากร และลำดับความก้าวหน้าที่ใช้จริง
- ตรวจภาพที่ผู้ใช้เลือกให้ครบก่อนนำไปใช้เป็นมาตรฐาน asset
- วิธีสลับ host ที่เข้ากับข้อกำหนดให้มีเพียงการบังคับทิศทาง

ค่าตัวเลขและระบบตัวอย่างในคำตอบผู้ช่วยไม่ควรถูกถือเป็นข้อกำหนดที่ผู้ใช้ยืนยันทุกข้อ

## จุดเริ่มต้นที่เสนอสำหรับต้นแบบ

1. Lab แบบชั่วคราว: ผสมสารไม่กี่ชนิดและบันทึกสูตร
2. กดเริ่ม = ฉีด เข้าแผนที่ 3D isometric ในร่างมนุษย์ แสดงอาการก่อนกลายโดยไม่บอกเวลา
3. เดิน → ล่าอัตโนมัติ → ใช้ stamina → กัด → AI แพร่เชื้อต่อ
4. จบรอบและบันทึก Experiment History เพื่อปรับสูตรและทดลองซ้ำ
5. เพิ่มการตรวจจับสายตา/กลิ่น กลางวันกลางคืน และระบบรักษา
6. ทดสอบการสลับ host และใช้โมเดล modular จริง

ต้นแบบควรพิสูจน์วงจรทดลองยาและปรับสูตรครบหนึ่งรอบ ก่อนขยายเมืองและ asset จริง
กลไกสลับร่างต้องออกแบบ input เพิ่ม เนื่องจากข้อกำหนดช่วงเล่นเดิมระบุให้มีเพียงการบังคับทิศทาง
