# I Made Zombies

ต้นแบบเกม Godot 4.7 แนวนอน 1280 × 720 ผู้เล่นเป็นนักวิทยาศาสตร์ที่ทดลองเซรุ่มกับตัวเองและเริ่มการระบาด

## เริ่มใช้งาน

เปิด project.godot ใน Godot 4.7 แล้วกด F5 จุดเริ่มต้นคือ game/app/main.tscn

## สิ่งที่เล่นได้

- หน้าโหลดและหน้าแล็บแบบภาพ พร้อมภาพประกอบเมนูและ animation เมื่อ hover/click
- Stages, Lab, Collection และ Records: เลือก Community ปรับส่วนผสม บันทึกสูตร และดูประวัติ
- Play: ฉาก 3D dummy มุม isometric กับคน 2 คน คลิกซ้ายบนพื้นเพื่อเดิน หลังกลายร่างจะไล่กัดอัตโนมัติเมื่อเข้าใกล้ ใช้ stamina ระหว่างล่า และ AI ที่ติดเชื้อช่วยแพร่เชื้อต่อ
- ติดเชื้อครบจะจบรอบและบันทึกผลใน Experiment History กด Esc เพื่อกลับหน้าแล็บ

ข้อมูลสูตรและประวัติเก็บใน user://research_ui.json ของเครื่องผู้เล่น

## ขอบเขตต้นแบบ

ใช้ dummy และพื้นที่โล่ง ยังไม่มี pathfinding รอบสิ่งกีดขวาง โมเดลจริง ระบบวัคซีน กฎแพ้ สลับ host หรือวงจรกลางวันกลางคืน ค่าของเซรุ่มและ stamina เป็นค่าทดลอง

## ตรวจสอบ

รัน Godot ด้วย -- --smoke-test เพื่อตรวจเมนูและหน้าย่อย หรือ -- --play-test เพื่อตรวจวงจรการเล่นและบันทึกผล การทดสอบใช้ไฟล์บันทึกแยกจากผู้เล่น
