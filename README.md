# I Made Zombies

ต้นแบบเกม Godot 4.7 แนวนอน 1280 × 720 ผู้เล่นเป็นนักวิทยาศาสตร์ที่ทดลองเซรุ่มกับตัวเองและเริ่มการระบาด

## เริ่มใช้งาน

เปิด project.godot ใน Godot 4.7 แล้วกด F5 จุดเริ่มต้นคือ game/app/main.tscn

## สิ่งที่เล่นได้

- หน้าโหลดและหน้าแล็บแบบภาพ พร้อมภาพประกอบเมนูและ animation เมื่อ hover/click
- Stages, Lab, Collection และ Records: เลือก Community ปรับส่วนผสม บันทึกสูตร และดูประวัติ
- Play: ฉาก 3D dummy มุม isometric กับคน 24 คนในฉากที่ขยายแล้ว คลิกซ้ายบนพื้นเพื่อเดิน หลังกลายร่างจะไล่กัดอัตโนมัติเมื่อเข้าใกล้ ใช้ stamina ระหว่างล่า กระโดดกัดและล้มคู่ เหยื่อนอนนิ่ง กระตุก ลุกขึ้นกลายร่าง และ AI ที่ติดเชื้อช่วยแพร่เชื้อต่อ
- ช่วงแรกคนยังสงสัย ตำรวจประเมินภัยก่อนยิงช้าลง คนทั่วไปเริ่มป้องกันตัวเมื่อการระบาดดำเนินไปแล้ว วัคซีนต้องศึกษาศพซอมบี้ไม่ซ้ำ 5 ร่างและรอผลิตก่อนใช้
- มีคนถือไม้เบสบอลตีผลักซอมบี้ ตำรวจถือปืนถอยยิงและรีโหลด และคนถือวัคซีนรักษาผู้ติดเชื้อกลับเป็นคน พร้อมภูมิคุ้มกันชั่วคราว
- ซอมบี้หลายตัวไล่เหยื่อเดียว กระโดดรุมกัดจากคนละมุมได้สูงสุด 8 ตัว และการตีหรือยิงหยุดผู้โจมตีเพื่อช่วยเหยื่อได้
- ติดเชื้อครบจะจบรอบและบันทึกผลใน Experiment History กด Esc เพื่อกลับหน้าแล็บ

ข้อมูลสูตรและประวัติเก็บใน user://research_ui.json ของเครื่องผู้เล่น

## ขอบเขตต้นแบบ

ใช้ dummy และพื้นที่โล่ง ยังไม่มี pathfinding รอบสิ่งกีดขวาง โมเดลจริง ระบบโรงพยาบาล/ผลิตวัคซีน สลับ host หรือวงจรกลางวันกลางคืน ค่าของเซรุ่ม stamina และอาวุธเป็นค่าทดลอง ผู้เล่นตายหรือผู้ติดเชื้อถูกกำจัด/รักษาหมดจะจบรอบแบบแพ้

## ตรวจสอบ

รัน Godot ด้วย -- --smoke-test เพื่อตรวจเมนูและหน้าย่อย หรือ -- --play-test เพื่อตรวจวงจรการเล่นและบันทึกผล การทดสอบใช้ไฟล์บันทึกแยกจากผู้เล่น
